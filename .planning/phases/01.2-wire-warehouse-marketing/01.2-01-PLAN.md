<action>
In `backend/app/api/v1/warehouse.py`:
1. Add GET `/parts/{id}/movements` — list movements for a part, filterable by type
2. Add POST `/movements` — create movement:
   - Validate part exists and is_active (not soft-deleted)
   - For type='out': validate part.quantity >= movement.quantity
   - Auto-update part.quantity: 'in' adds, 'out' subtracts
   - Return 400 if insufficient stock for 'out'
3. Add DELETE `/movements/{id}` — soft delete movement? Or hard delete with quantity rollback? Decision: hard delete is OK for movements (they're transactional logs), rollback quantity.
</action>
