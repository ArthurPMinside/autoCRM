<action>
In `backend/app/api/v1/analytics.py`:
1. GET `/analytics/rfm` — return real RFM segments:
   - Calculate Recency (days since last order), Frequency (order count), Monetary (total revenue) per client
   - Segment into: Champions, Loyal, Potential, New, At Risk, Lost
   - Return segment counts for pie chart
2. GET `/analytics/retention` — return real cohort data:
   - Group clients by first_order_month
   - Calculate return rate at 1, 3, 6, 12 months
   - Return: cohort_month, initial_count, return_1m, return_3m, return_6m, return_12m
3. GET `/analytics/revenue` — return real revenue by service:
   - Sum total_cost from work_orders GROUP BY service_id
   - Join with services for name
   - Return: service_name, revenue, order_count
4. Verify GET `/analytics/sources` already works (marketing source attribution)
</action>
