# Plan 01: Complete CRUD Operations

## Objective
Add missing PUT/DELETE endpoints for clients, vehicles, parts, and work_orders with soft-delete semantics. Wire frontend UI to use real API calls for update and delete operations.

## Context
- `.planning/phases/01.1-complete-crud/01.1-CONTEXT.md`
- `backend/app/models/` — SQLAlchemy models
- `backend/app/api/v1/` — existing router patterns
- `web/src/pages/` — frontend pages
- `web/src/api/` — API client modules

<action>
In `backend/app/api/v1/clients.py`:
1. Add PUT `/clients/{id}` endpoint that updates name, phone, email. Return updated client.
2. Add DELETE `/clients/{id}` endpoint that:
   - Checks if client has any work_orders with status NOT IN ("cancelled", "completed") AND is_deleted=False
   - If active orders exist: return 409 with detail="Cannot delete client with active work orders"
   - Otherwise: set is_deleted=True, return 204
3. Update GET `/clients/` to filter `is_deleted=False`
4. Update GET `/clients/{id}` to return 404 if `is_deleted=True`
</action>

## Verification

<verification>
1. Start backend: `cd backend && source venv/bin/activate && uvicorn app.main:app --host 0.0.0.0 --port 8001`
2. Test PUT client: `curl -X PUT http://localhost:8001/api/v1/clients/{id} -H "Content-Type: application/json" -d '{"name":"Updated Name","phone":"+79991234567","email":"updated@test.ru"}'`
3. Test DELETE client with active order: should return 409
4. Test DELETE client without active orders: should return 204, GET should return 404
5. Repeat for vehicles, parts, work_orders
6. Start frontend: `cd web && npm run dev`
7. Manually verify: edit client, delete client (with confirmation), delete work order
</verification>
